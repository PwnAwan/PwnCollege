The challenge checks for a specific parent process : python
The challenge will make sure that stdin is redirected from a fifo
The challenge will check for a hardcoded password over stdin : dvpnhqvk
Write the python script as:
import os
import glob
from pwn import *

bin_path = glob.glob('/challenge/embryoio_level103')[0]

myfifo = 'fifofile'
if os.path.exists(myfifo):
    os.remove(myfifo)

os.mkfifo(myfifo, 0o666)

pipe_read = os.open("fifofile", os.O_RDWR)
pipe_write = os.open("fifofile", os.O_WRONLY)

p1 = process(["cat", "-"], stdout=pipe_write)
p1.sendline(b"dvpnhqvk")
p2 = process([bin_path], stdin=pipe_read)
time.sleep(1)

print(p2.read(4096).decode())

os.close(pipe_write)
os.close(pipe_read)

Run the script as python script.py and it will show the flag.
