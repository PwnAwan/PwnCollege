Read the challenge file by typing /challenge/embryoio_level91
The challenge checks for a specific parent process : shellscript
The challenge will make sure that stdout is a redirected from fifo
Write the script.sh code as:
#!/usr/bin/env
rm /tmp/testfifo
mkfifo /tmp/testfifo
/challenge/embryoio_level91 > /tmp/testfifo
Run the command as bash script.sh in one terminal and run "cat /tmp/testfifo" in other terminal(both at the same time like 1st and 2nd).
It will execute the first terminal command and show the flag.
