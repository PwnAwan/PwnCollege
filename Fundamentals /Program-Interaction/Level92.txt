Read the challenge file by typing /challenge/embryoio_level92
The challenge checks for a specific parent process : shellscript
The challenge will make sure that stdin is redirected from a fifo
The challenge will make sure that stdout is a redirected from fifo
The challenge will check for a hardcoded password over stdin : hprrtwgz
Write the script.sh code as:
#!/usr/bin/env
rm /tmp/testfifo
mkfifo /tmp/testfifo
rm /tmp/testfifo2
mkfifo /tmp/testfifo2
/challenge/embryoio_level92 < /tmp/testfifo > /tmp/testfifo2
Run the command as bash script.sh in one terminal and run "echo hprrtwgz > /tmp/testfifo" in other terminal(both at the same time like 1st and 2nd).
Then enter "cat /tmp/testfifo2" in the 2nd terminal. It will show the flag.
